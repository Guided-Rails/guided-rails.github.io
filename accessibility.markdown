# Accessibility

_Last reviewed September 30, 2026_

We help teams build accessible Rails apps, so we hold this site to the same bar. We aim to meet [WCAG 2.2](https://www.w3.org/TR/WCAG22/) at level AA.

**How we test.** We check pages with VoiceOver on macOS, with the keyboard alone, and at 200% zoom.

**Audio.** Posts that include screen reader recordings also include a written transcript of each clip.

**Known limitations.** Styles load from the Tailwind CSS CDN. If that CDN is unavailable, pages still work but lose their styling.

**Found a barrier?** Email [{{ site.email }}](mailto:{{ site.email }}) and tell us the page and what went wrong. We'll reply within two business days.
