Small, focused gems we've built for our own Rails apps and shared with everyone.

a11y-lint

Catch accessibility issues in ERB and Phlex views before they ship, like images without alt text and links or buttons without an accessible name.

{% highlight console %} $ a11y-lint app/views app/views/home.html.erb:3 [ImgMissingAlt] img tag is missing an alt attribute (WCAG 1.1.1) 1 offense found {% endhighlight %}

minitest-attributes

Assert several attributes of an object in one call, with a clear failure message for each mismatch.

{% highlight ruby %} assert_attributes person, first_name: "Marceline", nickname: nil, created_at: Time.current {% endhighlight %}
GitHub RubyGems

guarda

Authorization built around controller actions, not models. Each controller gets a policy, and each action gets a policy method.

{% highlight ruby %} class PostsController < ApplicationController def update authorize @post # => PostsPolicy#update? end end {% endhighlight %}

uthmani_text_size

Archived

Count the letters in Uthmani Arabic text, ignoring the diacritics and marks that String#size counts as separate characters.

{% highlight ruby %} "ٱلرَّحْمَٰنِ".size # => 12 "ٱلرَّحْمَٰنِ".uthmani_size # => 6 {% endhighlight %}
