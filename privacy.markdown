# Privacy

_Last updated September 30, 2026_

This site doesn't use cookies, and it doesn't collect personal information.

**Analytics.** We use [Fathom Analytics](https://usefathom.com/legal/compliance) to count page views. Fathom doesn't use cookies or store IP addresses, and it can't identify individual visitors.

**Hosting.** The site is hosted on GitHub Pages and loads styles from the Tailwind CSS CDN. Like any web server, these services may log your IP address when you visit.

**Email.** If you email us, we use your message only to reply and to work with you. We don't share it or add you to a mailing list.

**Questions?** Email [{{ site.email }}](mailto:{{ site.email }}).
